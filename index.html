💡 怎么算？
A=0 … Z=25，字母串就是26进制数。HELLO = H×26⁴+E×26³+L×26²+L×26+O。Z+B=BA 正好是25+1=26产生进位，和二进制进位一模一样，只是“逢26进1”。
🧠 指令集 Letter-ISA v1
LDA / ADD / SUB / MUL / DIV / STA / JMP / JZ / JNZ / OUT / HLT
操作数可以是字母立即数 B、字母串 HELLO、内存名 DATA；数据定义 COUNT = E。
🔬 为什么好玩？
一个 Lit 有26种状态 ≈ 4.7 bit。指令助记符本身就是英文单词，程序读起来像英语句子。这是三进制(Setun)、十进制(ENIAC)之后的一次“字母进制”思想实验。
